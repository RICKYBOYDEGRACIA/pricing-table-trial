# Pricing Table

A responsive pricing table project created as part of a [devchallenges.io](https://devchallenges.io/) frontend challenge.

## Overview

This project presents subscription plans in a clear, easy-to-compare layout. It focuses on responsive design, visual hierarchy, and an accessible user experience across different screen sizes.

## Features

- Responsive pricing table layout
- Clearly organized plans and features
- Prominent call-to-action buttons
- Mobile- and desktop-friendly design

## Built With

- HTML5
- CSS3

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Challenge

This project is part of the challenges available on [devchallenges.io](https://devchallenges.io/), a platform for practicing frontend development through real-world projects.
